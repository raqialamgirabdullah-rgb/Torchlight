# My Torch App

## অ্যান্ড্রয়েড অ্যাপ (APK)

`android/` ফোল্ডারে নেটিভ অ্যান্ড্রয়েড টর্চলাইট অ্যাপ আছে (Kotlin): বড় অন/অফ বাটন, **স্থির / SOS / ঝলক** মোড।
ক্যামেরা পারমিশন লাগে না।

**ভলিউম বাটনে টর্চ:** ভলিউম-ডাউন বাটন চেপে ধরলে (~০.৬ সেকেন্ড) টর্চ অন/অফ হয়, অ্যাপ বন্ধ বা স্ক্রিন অফ থাকলেও। চালু করতে অ্যাপ খুলে নিচের হিন্টে চাপ দিন, তারপর ফোনের Accessibility সেটিংসে "টর্চলাইট ভলিউম বাটন" অন করুন। ছোট চাপে ভলিউম আগের মতোই কমে।

APK বানায় GitHub Actions (`.github/workflows/build-apk.yml`),
তৈরি APK **Releases** পেজে `Torchlight.apk` নামে পাওয়া যায়। ইনস্টলের সময় ফোনে "অজানা সোর্স থেকে ইনস্টল" চালু করতে হবে।

**আপডেট সিস্টেম:** অ্যাপ খুললে নিজে থেকে GitHub Releases-এ নতুন সংস্করণ খোঁজে। নতুন সংস্করণ থাকলে নিচে "নতুন সংস্করণ এসেছে — আপডেট করুন" বাটন আসে; চাপলে অ্যাপের ভেতরেই APK নামে (প্রগ্রেস দেখায়) এবং ইনস্টলের নিশ্চিতকরণ পর্দা খোলে। প্রথমবার "অজানা সোর্স" অনুমতি দিতে হতে পারে। কোড পুশ করলেই GitHub Actions নতুন রিলিজ বানায় (সংস্করণ নম্বর = ১০০ + বিল্ড নম্বর), আর ফোনের অ্যাপ সেটা ধরে ফেলে।

# My Torch App

## অ্যান্ড্রয়েড অ্যাপ (APK)

`android/` ফোল্ডারে নেটিভ অ্যান্ড্রয়েড টর্চলাইট অ্যাপ আছে (Kotlin): বড় অন/অফ বাটন, **স্থির / SOS / ঝলক** মোড।
ক্যামেরা পারমিশন লাগে না। APK বানায় GitHub Actions (`.github/workflows/build-apk.yml`),
তৈরি APK **Releases** পেজে `Torchlight.apk` নামে পাওয়া যায়। ইনস্টলের সময় ফোনে "অজানা সোর্স থেকে ইনস্টল" চালু করতে হবে।
